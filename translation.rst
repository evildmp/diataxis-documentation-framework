Help translate Diátaxis
=======================

If you'd like to help translate Diátaxis into your language, that would be very welcome.

The best way to contribute to translation is to `Join the project on Transifex <https://app.transifex.com/join/?o=danieleprocida&p=diataxis&t=opensource>`_.

Transifex is set up for translation into French, Portuguese (Brazil), German, Korean, Chinese (Simplified) and Spanish. Other languages can be set up on request by :ref:`emailing me <contact>`.

As soon as a translation is complete, I will publish it on https://diataxis.fr.

There's a `staging version of this site with translations <https://diataxis-translated.readthedocs.io>`_.
